# WH78 Beta b10 — patch поверх текущего проекта

Этот архив предназначен для накладывания поверх текущей папки `~/Projects/WH78-Beta-b10`, которая сейчас содержит исходники b9.

Изменения:
- build id -> b10, versionCode -> 15;
- нижняя панель: на светлой теме возвращён светлый активный индикатор вместо чёрной плашки;
- неактивный ToggleSwitch: серый кружок и серый трек; активный — цвет текущей темы;
- убран старый логотип Amnezia из пустого списка туннелей;
- Quick Settings теперь использует прозрачную белую монохромную иконку WH78 вместо старой иконки Amnezia;
- иконка Quick Settings также задана как icon у QuickTileService.

Установка:
1. Распаковать архив прямо в текущий проект:
   cd ~/Projects/WH78-Beta-b10
   unzip -o ~/Загрузки/WH78-Beta-b10-patch.zip
2. Собрать:
   ./gradlew :ui:assembleDebug

`clean` не требуется.
